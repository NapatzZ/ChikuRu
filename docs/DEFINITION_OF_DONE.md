# Definition of Done

A task (issue) is **Done** only when every box below is true.

## Code
- [ ] Behaviour matches the issue's acceptance criteria.
- [ ] Runs with no console errors on a fresh load (Chrome + Firefox).
- [ ] New code is in its own module; `src/game.js` stays a thin orchestrator.
- [ ] Constants live in `src/config.js`, not scattered magic numbers.
- [ ] `npm run lint` passes.

## Collaboration
- [ ] Branch named `feat/…`, `fix/…`, or `docs/…`.
- [ ] Conventional-commit messages.
- [ ] PR uses the template and links the issue with `Closes #N`.
- [ ] At least one approving review from a non-author.
- [ ] Review comments are resolved or answered in writing.

## Communication (ENG COMMU)
- [ ] Issue, PR description, and review thread are in clear English.
- [ ] PR description explains *what* and *why*, not just *how*.
- [ ] Any scope change is stated in the PR, not done silently.

## Docs
- [ ] README / controls updated if player-facing behaviour changed.
- [ ] Sprint note updated with what shipped.
